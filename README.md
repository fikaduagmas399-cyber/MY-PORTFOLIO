# My Personal Portfolio Website

This is my personal portfolio website built to showcase my skills, projects, and professional background.

## Tech Stack
* **Design:** Figma
* **Frontend:** HTML5, CSS3, JavaScript (ES6+)
* **Version Control & Tools:** Git, GitHub, VS Code

## Features
* **Fully Responsive:** Optimised for all screen sizes (mobile, tablet, and desktop).
* **Modern UI/UX:** Clean and modern design crafted first in Figma and developed with CSS.
* **Contact Form:** A dedicated section for visitors to reach out and send messages directly.

## How to Run This Project Locally
To view and test this project on your local machine, follow these simple steps:

1. Clone the repository:
   ```bash
   git clone https://github.com/fikaduagmas399-cyber/MY-PORTFOLIO.git
   ```
2. Navigate to the project directory:
   ```bash
   cd MY-PORTFOLIO
   ```
3. Open the `index.html` file in any modern web browser.
